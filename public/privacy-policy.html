오마주(Omaju) 개인정보처리방침

시행일자: 2026년 9월 20일

'오마주(Omaju)'(이하 '서비스')는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령, 구글 플레이 개발자 정책을 준수하고 있습니다. 본 개인정보처리방침은 서비스가 수집하는 정보, 이용 목적, 보관 및 파기 기준, 이용자의 권리 등을 설명합니다.

1. 수집하는 개인정보 항목 및 이용 목적

서비스는 회원가입 없이도 핵심 기능을 이용할 수 있으며, 서비스 제공에 필수적인 최소한의 정보만을 처리합니다.

구분 수집/처리 항목 이용 목적 처리 방식
위치 정보 (GPS) 기기의 현재 위도·경도 좌표 (정확한 위치 / 대략적인 위치) 현재 위치 기반의 주변 장소(맛집, 카페, 명소 등) 검색 및 추천 검색 요청 시 일시적(Ephemeral)으로 처리되며, 서버에 저장되지 않음
오디오/음성 데이터 마이크를 통한 음성 입력 데이터 음성 명령 및 음성 검색의 텍스트 변환(Speech-to-Text) 기기 및 시스템 음성 인식 API를 통해 실시간 텍스트 변환 후 즉시 파기 (오디오 파일 미보관)
기기 및 서비스 로그 기기 모델명, OS 버전, 앱 오류 로그 앱 오류 수정 및 서비스 품질 개선 통계적 분석을 위한 비식별 익명 처리
알아두세요: 오마주는 사용자의 위치 정보 및 음성 녹음 파일을 자체 원격 서버에 수집·영구 저장하지 않습니다. 장소 탐색과 음성 인식은 기기 내부 또는 공개 검색 API 호출 시 일시적으로만 연산 처리(Ephemeral Processing)됩니다.

2. 개인정보의 보유 및 이용 기간

  • 위치 정보: 앱 내에서 위치 검색 및 추천을 수행하는 동안 메모리 및 기기 로컬 캐시에만 일시 저장되며, 앱 종료 시 또는 캐시 갱신 시 자동 삭제됩니다. (자체 서버 영구 저장 없음)
  • 음성 데이터: 텍스트 변환 처리가 완료되는 즉시 메모리에서 소멸되며, 별도의 오디오 파일로 저장되지 않습니다.

3. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 단, 장소 검색 등 서비스 본연의 기능 제공을 위해 아래와 같은 제3자 API가 사용됩니다:

  • 카카오 로컬 API (Kakao): 이용자가 위치 기반 검색을 요청한 경우, 해당 좌표 주변의 공개 장소 정보를 불러오기 위해 사용됩니다.

4. 개인정보의 기술적·관리적 보호 대책

  • 데이터 전송 암호화: 서비스 통신은 최신 암호화 프로토콜(HTTPS/TLS)을 통해 안전하게 전송됩니다.
  • 최소 권한 원칙: 필요한 시점에만 사용자로부터 직접 위치/마이크 권한을 요청(런타임 권한)하며, 허용하지 않더라도 수동 지역 선택을 통해 서비스를 계속 이용할 수 있습니다.
